# Флора Ленских столбов

Офлайн-прототип мобильного определителя редких и исчезающих растений национального парка «Ленские столбы» на Flutter для Android и iOS.

## Что реализовано

- каталог 23 видов с русскими и латинскими названиями, семействами, охранным статусом, описаниями, признаками, сроками цветения и зонами парка;
- поиск и фильтры по окраске цветка, форме листа, высоте, местообитанию и месяцу цветения;
- пошаговый многопризнаковый определитель с вариантами «не знаю», возвратом на шаг и близкими совпадениями;
- офлайн-карта-схема пяти туристско-рекреационных зон;
- карточка вида, чек-лист встреченных растений и достижения;
- викторина, входной и итоговый опросы;
- локальное хранение результатов, сообщений о находках и фото;
- очередь синхронизации при появлении подключения через `SYNC_URL`.

## Запуск

```bash
flutter pub get
flutter test
flutter run
```

Каталог 23 видов, карта и фотографии карточек лежат в `assets/` и доступны без интернета. Перед публикацией заказчик подтверждает права на тексты, фото и звук: список файлов собран в `docs/prava.md`. На карте показаны зоны парка, не точные точки редких растений.

Для включения отправки накопленных данных задайте параметры сборки:

```bash
flutter run --dart-define=SYNC_URL=https://example.org --dart-define=SYNC_API_KEY=...
```
