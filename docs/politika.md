## Какие данные есть в приложении

Аккаунта нет. Рекламы и счётчиков посещений нет. Эта версия ничего не отправляет на сервер парка.

На телефоне сохраняются имя, выбранный режим, коллекция, результат викторины, экскурсии гида и его материалы, наблюдения и отчёты инспектора, сообщения о находках и опросы. Викторина и записи инспектора предназначены только для этого телефона.

Местоположение запрашивается, только когда человек сам отмечает точку или открывает карту, и только пока приложение открыто. Камера и галерея используются, когда человек сам делает или выбирает снимок. Сравнение фото с карточками выполняется на телефоне.

Файл «Мои данные» уходит только туда, куда человек сам его отправит через меню телефона. Удаление приложения стирает сохранённые в нём записи: серверной копии у парка нет.

Вопрос о данных можно написать на fgbunpls@mail.ru. Если парк подключит отправку сообщений о находках на сервер, этот текст нужно обновить до выпуска такой версии.
